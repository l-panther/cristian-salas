# Cristian Salas Photography

## Description

A digital photography portfolio created for **Cristian Salas**, designed to showcase selected photographic work through a clean, visual, and responsive online experience.

Built with **Astro**, the website places photography at the centre of the design, providing dedicated areas for featured work, archived projects, video content, and information about the photographer.

## Features

- Responsive photography portfolio
- Selected photography galleries
- Photography archive
- Video content and playback
- About the photographer section
- Contact page
- Responsive navigation for desktop and mobile
- Accessible and semantic markup
- Optimised static site generation with Astro
- Clean, image-focused interface

## Installation
To run the project locally:

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```

## Usage
- Access the development server at `http://localhost:3000`  
- Navigate through the site to view projects and content  
- Build the project for production:

```bash
npm run build
```
## Configuration
No additional configuration is required. Content can be updated within the source files.
